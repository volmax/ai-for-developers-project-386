# AGENTS.md — Rules for AI Agents

## Build & Check

- Always run `mise run check` before committing. It must pass.
- The pre-commit hook runs `mise run check` automatically.
- If a check fails, fix the root cause — do not disable or ignore the check.

## Formatting & Linting

- **Java**: `mvn spotless:apply -B -s /tmp/maven-settings.xml` to fix formatting.
- **TypeScript/JS**: `npm run format:fix` (oxfmt) and `npm run lint` (oxlint).
- Use `mise run fix` to auto-fix all formatting issues.

## Code Standards

- **Java**: Google Java Format (AOSP style) enforced by Spotless.
- **TypeScript**: Strict mode enabled, no unused locals/parameters.
- **Docker**: Follow Hadolint best practices (`.hadolint.yaml` in each directory).
- **GitHub Actions**: Pin actions to SHA, set `timeout-minutes`, use `concurrency`.

## Existing Code

- Do not refactor or fix lint issues in the same change that adds checks.
- Baseline ignores are in `frontend/knip.json` — do not remove them without approval.
- Hadolint ignores in `backend/.hadolint.yaml` and `frontend/.hadolint.yaml` are intentional.

## Security

- Never commit secrets, API keys, or credentials.
- Run `mise x betterleaks -- betterleaks dir . --no-banner` to scan for leaks.
- `.env.example` is safe — it contains no real values.

## CI

- `.github/workflows/hexlet-check.yml` — DO NOT modify or delete. Auto-generated by Hexlet.
- `.github/workflows/ci.yml` — main CI workflow. Updated by jactionlint.

## Toolchain

- Use `mise` for tool management. All tools are pinned in `mise.toml`.
- Maven settings with working central repo: `/tmp/maven-settings.xml`.
