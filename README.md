## Сценарий пользователя

В topbar приложения три кнопки `Записаться`, `Админка` и `Предстоящие встречи`:

- Пользователь нажимает на кнопку `Записаться` → Переход к сценарию по бронированию встречи.
- Пользователь нажимает на кнопку `Предстоящие встречи` → Переходит к странице со списком всех предстоящих встреч.

### Сценарий бронирования встречи

На главной странице размещена кнопка `Записаться`.

1. Пользователь нажимает `Записаться` → Переход на страницу с каталогом типов событий.
2. На странице каталога отображаются все доступные типы встреч, добавленные владельцем (например, «Консультация — 15 мин», «Глубокое погружение — 30 мин», «Менторство — 60 мин»).
   - Пользователь нажимает на нужный тип → Переход на страницу с выбором даты.
3. На странице выбора даты размещён календарь на текущий месяц. В календаре можно выбрать дату на ближайшие 14 дней. Рядом с календарём блок, в котором отображаются свободные и занятые слоты в этом дне. Под списком слотов расположена кнопка `Продолжить`.
   - Пользователь выбирает дату → Обновляется список слотов. Загружаются все слоты для выбранной даты.
   - Пользователь выбирает свободный слот → Становится активной кнопка `Продолжить`.
   - Пользователь нажимает `Продолжить` → Переход на страницу с подтверждением бронирования.
4. На странице подтверждения размещена кнопка `Забронировать ещё`.
   - Пользователь нажимает `Забронировать ещё` → Переход на страницу с каталогом типов событий.

### Отказ повторного бронирования

Если пользователь пытается забронировать уже занятый слот, система возвращает ошибку `409 Conflict` с сообщением о пересечении. На UI отображается ошибка бронирования.

### Сценарий владельца

Владелец может управлять бронированиями и типами встреч:

- Просматривать предстоящие бронирования через страницу `Предстоящие встречи`, где отображается полный список всех забронированных встреч с информацией о госте и времени.
- Создавать новые типы встреч через панель администратора `/admin` → «Добавить тип встречи».

### Админка

Панель управления доступна по адресу `/admin`. Содержит две основные функции:

**Предстоящие встречи** — полный список бронирований с информацией о госте (имя, email), типе встречи, времени начала и окончания.

**Добавить тип встречи** — форма создания нового типа встречи с полями:
- Название — уникальное имя типа (например, «Менторство»)
- Описание — что включает эта встреча
- Длительность — выпадающий список от 15 до 540 минут с шагом 15 минут

После создания новый тип сразу появляется в каталоге доступных встреч.

## Важное

Данные **не сохраняются** между перезапусками контейнера. Приложение использует H2 in-memory базу данных — при остановке контейнера все бронирования удаляются.
