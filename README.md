## Сценарий пользователя

В topbar приложения две кнопки `Записаться` и `Предстоящие события`:

- Пользователь нажимает на кнопку `Записаться` → Переход к сценарию по бронированию встречи.
- Пользователь нажимает на кнопку `Предстоящие события` → Переходит к странице со списком всех предстоящих встреч.

### Сценарий бронирования встречи

На главной странице размещена кнопка `Записаться`.

1. Пользователь нажимает `Записаться` → Переход на страницу с выбором типа события.
2. На странице выбора типа события два варианта — `Встреча 15 минут` и `Встреча 30 минут`.
   - Пользователь нажимает на один из вариантов → Переход на страницу с выбором даты.
3. На странице выбора даты размещён календарь на текущий месяц. В календаре можно выбрать дату на ближайшие 14 дней. Рядом с календарём блок, в котором отображаются свободные и занятые слоты в этом дне. Под списком слотов расположена кнопка `Продолжить`.
   - Пользователь выбирает дату → Обновляется список слотов. Загружаются все слоты для выбранной даты.
   - Пользователь выбирает свободный слот → Становится активной кнопка `Продолжить`.
   - Пользователь нажимает `Продолжить` → Переход на страницу с уведомлением об успешном бронировании.
4. На странице подтверждения размещена кнопка `Забронировать ещё`.
   - Пользователь нажимает `Забронировать ещё` → Переход на страницу с выбором типа события.

### Отказ повторного бронирования

Если пользователь пытается забронировать уже занятый слот, система возвращает ошибку `409 Conflict` с сообщением о пересечении. На UI отображается ошибка бронирования.

### Сценарий владельца

Владелец может просматривать предстоящие бронирования через страницу `Предстоящие события`, где отображается полный список всех забронированных встреч.

## Важное

Данные **не сохраняются** между перезапусками контейнера. Приложение использует H2 in-memory базу данных — при остановке контейнера все бронирования удаляются.
