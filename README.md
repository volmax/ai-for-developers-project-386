## Сценарий пользователя

В topbar приложения две кнопки `Записаться` и `Предстоящие события`
	- Пользователь нажимает на кнопку `Записаться` -> Переход к сценарию по бронированию встречи.
	- Пользователь нажимает на кнопку `Предстоящие события` -> пользователь переходит к странице, на которой размещён список всех предстоящих встреч.

Сценарий пользователя по бронированию встречи:
На главной странице размещена кнопка `Записаться`. 
	- Пользователь нажимает на главной странице кнопку `Записаться` -> Переход на страницу с выбором типа события.
На странице с выбором типа события два выбор из двух вариантов - `Встреча 15 минут` и `Встреча 30 минут`. 
	- Пользователь нажимает на один из вариантов -> Переход на страницу с выбором даты.
На странице с выбором даты размещён календарь на текущий месяц. В календаре можно выбрать дату на ближайшие 14 дней. Рядом с календарём блок, в котором отображаются свободные и занятые слоты в этом дне. Под списком слотов расположена кнопка `Продолжить`
	- Пользователь выбирает дату в календаре -> Обновляется список слотов. В него загружаются все слоты для выбранной даты.
	- Пользователь выбирает свободный слот -> Становится активной кнопка `Продолжить`
	- Пользователь нажимает `Продолжить` -> Переход на страницу с уведомлением о успешном бронировании встречи.
На странице с уведомлением о успешном бронировании встречи размещена кнопка `Забронировать ещё`. 
	- Пользователь нажимает кнопку `Забронировать ещё` -> Переход на страницу с выбором типа события.
